# Commands

| Command                | Action                                           |
|:-----------------------|:-------------------------------------------------|
| `pnpm install`         | Installs dependencies                            |
| `pnpm dev`             | Starts local dev server at `localhost:4321`      |
| `pnpm build`           | Build your production site to `./dist/`          |
| `pnpm preview`         | Preview your build locally, before deploying     |
| `pnpm astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `pnpm astro -- --help` | Get help using the Astro CLI                     |
| `pnpm astro check`     |                                                  |
| `pnpm astro sync`      |                                                  |

| Command                        | Action                                             |
|:-------------------------------|:---------------------------------------------------|
| firebase login                 | Log in to your Firebase account                    |
| firebase init                  | Initialize Firebase services in your project       |
| firebase deploy                | Deploy your app to Firebase Hosting                |
| firebase serve                 | Serve your app locally for testing                 |
| firebase open hosting:site     | Open your live Firebase-hosted site in browser     |
| firebase logout                | Log out of your Firebase account                   |
| firebase projects:list         | List all your Firebase projects                    |
| firebase use --add             | Add and alias a Firebase project to your workspace |
| firebase deploy --only hosting | Deploy only the hosting part of your project       |
